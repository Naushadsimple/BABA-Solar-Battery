## 🌟 Key Features

- **🎨 Ultra-Modern Glassmorphism Design**: Frosted glass cards, pill badges, subtle drop shadows, and brand orange gradient accents (`#E84C0A` to `#F7A01D`).
- **📱 6 Fully Interactive Pages**:
  - `Home`: Parallax hero, live solar stats, interactive 5-step numbered accordion, commitment banner, project showcase, customer testimonial carousel.
  - `About`: Heritage timeline (2015–2026), mission/vision, safety standards, leadership & engineering team profiles.
  - `Services`: 6 comprehensive solar packages with specifications, On-Grid vs Off-Grid vs Hybrid comparison matrix, 4-step installation workflow.
  - `Gallery`: Filterable project showcase with interactive modal dialogs for technical specs.
  - `Blogs`: Solar technical articles, PM Surya Ghar subsidy guide (Gujarat), downloadable 2026 Solar Handbook.
  - `Contact`: Interactive feasibility inquiry form with prefill support, direct WhatsApp chat integration, Google Maps location iframe, and expandable FAQ accordion.
- **⚡ Fast & Smooth UX**: Smooth animations powered by Framer Motion, instant route scroll-to-top restoration, and 100% reliable local image assets.

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/Naushadsimple/BABA-Solar-Battery.git
cd BABA-Solar-Battery
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
node .\node_modules\vite\bin\vite.js --host
```
Open **[http://localhost:5173](http://localhost:5173)** in your browser.

### 4. Build for production
```bash
node .\node_modules\vite\bin\vite.js build
```
